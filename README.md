# نشریه حاشیه‌ساز | HashiyehSaz

> گاهنامه مستقل افشاگری، تحلیل بحران‌های پلتفرمی و دیده‌بان حقوق کاربران وب فارسی

این وب‌سایت پورتال رسمی نشریه دیجیتال «حاشیه‌ساز» است که به صورت استاتیک روی **GitHub Pages** میزبانی می‌شود.

## دسترسی آنلاین
- **آدرس وب‌سایت:** [https://hashiyehsaz.github.io/](https://hashiyehsaz.github.io/)
- **نسخه چاپی PDF:** [دانلود پیش‌شماره ۱ (PDF)](assets/pdf/hashiyehsaz_issue_01.pdf)
- **درگاه سوت‌زنی تلگرام:** [@HashiyehsazBot](https://t.me/HashiyehsazBot)

## محتوای پیش‌شماره اول (آبان ۱۴۰۵)
1. **صفحه ۱ (جلد رو):** تله کنسلی جاباما؛ بدهی اقساط دیجی‌پی بدون یک ثانیه اقامت (پرونده رزرو ۳۳۲۴۳۹۷).
2. **صفحه ۲ (شناسنامه و سخن سردبیر):** یادداشت ریک سانچز با عنوان «پایان مدارا با شوهای تبلیغاتی و بدعهدی‌های صنفی».
3. **صفحه ۳ (گزارش تحلیلی ۳ ستونه):** کالبدشکافی تخلفات جاباما، بدعهدی یکتانت در پرداخت جوایز مسابقه رمزالمثل، و قطعی سرورهای bluCTF بلوبانک در کنار پاسخگویی معکوس روابط عمومی.
4. **صفحه ۴ (جلد پشت و مانیفست):** صدای اعتراض شما حاشیه نیست؛ اصل ماجراست + سامانه سوت‌زنی شهروندی.

## فناوری و دیزاین سیستم
- توسعه‌یافته مطابق با استانداردهای بومی **وایب‌فارسی (VibeFarsi)**
- فونت استاندارد وزیرمتن (بدون وابستگی به CDN خارجی و کاملا لودشونده در شبکه داخلی ایران)
- راست‌چین مطلق (RTL) بدون فاصله‌گذاری نامتعارف حروف
- سازگاری کامل با تمامی دیوایس‌ها، صفحات نمایش رتینا و موبایل
